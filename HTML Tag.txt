1. Document Structure & Root Elements
These mandatory tags establish the layout framework and identify document metadata.

<!DOCTYPE html>: Declares document type to the browser.<html>: Root element enclosing the entire document.
<head>: Container holding page metadata, styles, and scripts.
<body>: Houses all visible webpage content.
<title>: Displays the webpage title in browser tabs.
<meta>: Sets configuration details like character sets or keywords.
<link>: Hooks external resource files, such as CSS stylesheets.
<style>: Hosts internal CSS scripts natively.
<script>: Integrates or executes dynamic client-side JavaScript.
<noscript>: Handles rendering fallback when scripts are disabled.
